Factory의 AI 절반 — LLM 기반 제품을 만들 때 같은 프리미티브를 매번 다시 엮지 않게 해주는 재사용 토대.

## 들어있는 것

- **RAG** — pluggable retriever, 청크 전략, hybrid search 훅.
- **Agent workflow** — LangGraph 기반, state checkpoint + resumable 실행.
- **Eval harness** — LLM 전후 점수 매김. 검색 실패를 모델 탓으로 안 돌리게 됨.
- **Tool calling** — 타입 있는 tool 레지스트리, 스키마 검증, backoff 포함 재시도.
- **관측성** — 모든 LLM 호출이 prompt, output, latency, cost와 함께 로깅. 디버깅이 고고학이 아니게 됨.

## 왜 이 레이어가 필요한가

LLM으로 뭔가 만드는 팀들을 보면 모델 자체가 병목인 경우는 드물다 — 검색, tool 연결, eval 규율, 관측성이 진짜 병목이다. AI Core는 그것들을 기본값으로 만들기 위해 존재한다.

## 상태

- 작동하는 RAG 파이프라인 + eval 루프.
- LangGraph agent runtime 안정.
- Tool registry + observability 다음 출시.

Backend Core와 AI Core 위에 얹히는 레이어 — 기초를 매번 다시 만들지 않으니까 실제 제품이 빠르게 나옴.

## 여기 들어있는 것

Factory 위에 만들고 있거나 계획 중인 제품들:

- **Crosspost-bot** — MDX 한 벌에서 LinkedIn, X, Dev.to로 LLM 기반 자동 배포. (별도 프로젝트 페이지 참고.)
- **daeseon.ai** — 이 사이트. 같은 기초 위에 만들었지만 정적 렌더링에 맞게 Next.js로 가볍게.
- 더 추가 예정 — 각 제품이 코어의 다른 측면을 검증함.

## 왜 하나의 monorepo가 아니라 "factory"인가

세 가지 이유:

1. **Backend Core**와 **AI Core**가 각각 독립적으로 테스트 가능. 제품은 그냥 평범한 의존성으로 가져다 씀.
2. 한 코어를 다른 코어 건드리지 않고 교체 가능. (같은 auth 스택을 네 번 다시 만들어보고 배운 것.)
3. "공장" 비유는 목표를 정직하게 드러냄 — 플랫폼을 영원히 유지보수하는 게 아니라 제품을 출하하고 싶다.

## 상태

- 첫 제품 (crosspost-bot)이 두 코어를 모두 사용 중.
- 어떤 추상화가 실제 사용에서 살아남고 어떤 게 다시 만들어야 하는지 검증 중.

The layer on top of Backend Core and AI Core — actual products, built quickly because the foundations don&apos;t need re-building each time.

## What lives here

Products being built or planned on top of the factory:

- **Crosspost-bot** — LLM-driven distribution of a single MDX source to LinkedIn, X, Dev.to. (See its own project page.)
- **daseon.ai** — this site. Built on the same foundations but stripped down to static-friendly Next.js.
- More TBD — each one validates a different slice of the cores.

## Why a "factory" instead of one big monorepo

Three reasons:

1. **Backend Core** and **AI Core** are testable in isolation; products import them as boring dependencies.
2. Replacing one core without touching the others stays cheap. (Lesson from rebuilding the same auth stack 4 times.)
3. The factory metaphor is honest about the goal — I want to ship products, not maintain a platform forever.

## Status

- First product (crosspost-bot) consuming both cores.
- Validating which abstractions hold up under real use vs. which need rework.

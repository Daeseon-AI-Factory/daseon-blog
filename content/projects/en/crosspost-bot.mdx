A small tool I&apos;m building so I never write the same post three times. Source-of-truth is one MDX file; the bot re-styles it per platform, posts it, and tracks engagement back into a single dashboard.

## What it does

- Pulls a published post from this blog (via webhook trigger on publish).
- Asks an LLM to re-style the body per platform: punchy thread on X, longer narrative on LinkedIn, full canonical on Dev.to.
- Posts via each platform&apos;s API and stores the response IDs.
- A small dashboard tracks views/likes per platform so I can see what travels.

## Current state

- ✓ LinkedIn + X posting + write-back of IDs.
- ✓ Style-transfer prompt with calibration set.
- ☐ Dev.to integration.
- ☐ Engagement back-fill (poll once a day for 7 days).

## What I&apos;d redo

The style-transfer prompt was the hardest part. First version was too "LinkedIn guru" — I had to build a small eval set of *good* posts and iterate against it.

## What changed

The macOS terminal-deck product was renamed to **Talkak** and its site moved to `talkak.daeseon.ai` (the old `ddalkkak.daeseon.ai` 307-redirects to it). User-facing surfaces now say Talkak:

- Project page title + live link + hero image (en + ko)
- `/now` headline and project link label (en + ko)
- About page tool list (en + ko)
- The `showep12/showep12` GitHub profile README (Selected-work row)

## What deliberately did *not* change

The rename is the brand and the live URL — not the plumbing:

- **Repo stays `Daeseon-AI-Factory/ddalkkak`** (there is no `talkak` repo). `logSourceRepo` must equal the real repo name, or this very build's log pull 404s.
- **Internal code identifiers** that appear in the architecture deep-dive are real and stay: the tmux socket `-L dalkkak`, `DALKKAK_PANE_ID`, the data directory `DalkkakAI/`, the `@ddalkkak/*` packages, the bundle id `ai.ddalkkak.desktop`. The deep-dive already documents these four naming layers.
- **The route slug `dalkkak-ai`** is unchanged — changing it would rename six files and 404 existing inbound links to `daeseon.ai/projects/dalkkak-ai`.
- **Dated log entries** are immutable history.

## Open

- The about page still lists "TubeShadow" alongside Talkak; if that's a stale name for Mimi, it should be updated too — not assumed.
